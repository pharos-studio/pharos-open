## 1. v2 核心体验模型（本次重构的目标形态）

v2 不再是「一条自由滚动的长页」，而是一套**翻页式演示（full-page snap）**：

- **整页翻页**：页面一屏（viewport）一屏地显示；鼠标滚轮向下/向上 → 切到下一页/上一页（带 snap 过渡，不是自由滚动）。
- **3D 封面（初始页）**：第 1 页 = 三维灯塔海面场景作背景 + 标题覆盖层，作为「开场」。翻页离开封面后，正式内容介绍开始。
- **右侧导航轮**：屏幕右侧一条垂直导航（圆点/页码），标注**当前页名**（active 项展开显示名称），可点击跳转。
- **移动端**：上下滑手势 → 翻页；3D 封面支持触摸拖拽转视线；竖屏布局；低端机帧率/降级。

> ⚠️ 架构主干已定（岔路① 3D 仅第1页封面；岔路② tab 直接变页）。剩余细节（页清单合并、导航轮形态、埋点）见文末清单。

## 2. v2 目标与成功指标

### 2.1 目标
把「招牌 3D 首屏」升级为「有节奏的翻页式故事」，让访客一屏一屏被引导着读完，移动端同样可用，且低端机不崩。

### 2.2 成功指标（用户暂无明确数值目标 —— 采用「硬门 + 基线度量」两分法）
**A. 硬质量门（v2 必过，不可妥协）**
- 翻页过渡无卡顿：主线程无长任务（>50ms）阻塞；整页切换响应 < 300ms 感知。
- 3D 封面在低端机/软件渲染（SwiftShader）下平滑降级或主动降配，**不白屏、不卡死**。
- `prefers-reduced-motion: reduce` 下：整页演示退化为**普通可顺序滚动的长页**，导航轮仍可键盘/点击跳转。
- 颜色对比满足 WCAG AA；导航轮焦点可见。

**B. 基线度量（先建埋点，后定 KPI）**
- 当前页面**暂无明确 analytics 目标**。v2 先植入轻量埋点：封面→第 2 页转化率、各页抵达深度、平均完成率、单页平均停留。
- 上线 2~4 周后取 v2 基线，再与 v1 对比，回填具体 KPI 数值。
- *已定（2026-09-21）：当前站点无埋点，v2 先接一套极简隐私友好统计（事件级：封面→第2页转化、各页抵达深度、完成率、单页停留），上线 2~4 周后取基线再回填 KPI 数值。工具选型在 §9 实现阶段定（优先隐私友好、不依赖第三方 Cookie）。*

|---|---|---|

#### 5.1.2 整页翻页式滚动（full-page snap）—— 取代自由长滚动
- **翻页机制**：一屏一页；滚轮下/上 → 下一/上一页；过渡用 `transform` 位移 + 节流，避免每帧重排。
- **页内入场**：保留既有 `reveal`/`cascade` 一次性入场，作为「该页内容进入时」的动画；翻页本身是 snap 过渡，二者分层不冲突。
- **可达性**：reduced-motion 下整体退化为可顺序滚动的长页；导航轮键盘可达、焦点可见。
- **新增 token**：翻页缓动时长（建议新增一档 ~700–900ms 的翻页曲线，登记到 `:root`，不散落）。

#### 5.1.3 3D 首屏作为封面 / 初始页 ✅ 已定：仅第1页封面
- 第 1 页 = 3D 灯塔海面 + 标题覆盖层（封面），作为开场。
- **已确认（岔路① = (a) 仅封面）**：翻页离开封面后，3D 场景收束/隐藏，内容页是独立干净的版面，灯塔不在内容阶段出场。
- 实现要点：翻页过渡时场景做轻量推远/淡出，之后移出视口并停止渲染（释放 GPU）；reduced-motion 下封面直接静态显示，不进 3D 循环。

#### 5.1.4 现有 6 个页签（tab）与整页翻页的协调 ✅ 已定：tab 直接变页（A）
- 现状：落地页共有 8 个主区块（`hero` / `why` / `feat` / `algo` / `start` / `privacy` / `limits` / `faq`），其中 `feat`（功能）区块内嵌 6 个 tab（概览/决策/持仓/配置/复盘/设置）。
- **已确认（岔路② = A）**：6 个 tab 直接展开为 6 个整页，删除「点 tab 切换」，改用滚轮翻页；原 tab 的淡入淡出入场保留为该页内容的进入动画。
- **v2 整页清单（提案）**：
  1. 封面（hero，3D 灯塔海面 + 标题「PHAROS · 跑在你自己电脑上」）
  2. 为什么做它（why）
  3. 功能 · 概览（今天赚了多少）
  4. 功能 · 决策（现在能不能加）

#### 5.1.5 C. 移动端 / 触摸适配（已纳入 v2）
- 上下滑手势 → 翻页；3D 封面触摸拖拽转视线。
- 竖屏布局：一屏一页在窄屏下的排版（文字/卡片缩放、导航轮位置）。
- 低端机：帧率预算与降级（同 §5.1.1）；触摸翻页的惯性/边界处理。

#### 5.1.6 右侧导航轮形态 ✅ 已定（2026-09-23 修订：方案 A 扁平列表 → 弧形滚轮）
- **形态**：屏幕右侧一条**弧形页名列表**（13 项）。当前页清楚且染金（`--gold`）；越远离中心越模糊（+0.8px/项）、越淡（−13%/项，下限 0.2）；两端沿弧线向左微弯并轻微扭转。观感参考开源组件 OptionWheel，参数集中在 `WHEEL` 对象里。
- **实现路线（关键决策）= 原生移植，不引入 React**。三层理由：① 本项目定位「零依赖 Node + 原生前端、零构建」，而 OptionWheel 是 React/JSX 组件，引入需配套构建链或 CDN 运行时转译；② 它是**非受控**组件（只有 `defaultSelected` 初值，无法从外部设置当前项），而我们的需求恰是"翻页 → 轮盘跟随"——**即便用官方原版也必须改其源码**；③ 移植约 120 行，零依赖、参数可调。参考实现见 `index.html` 内的 `WHEEL` / `wheelSetup()`。
- **滚轮语义 = 跟随型**：滚轮**始终**归翻页引擎（滚轮翻页 → 轮盘跟着平滑滑过去）；轮盘本身只响应点击 / 指针拖动 / 键盘。避免"同一滚轮两种行为"的歧义。
- **交互**：点击任一项 → 直接翻到该页；指针拖动轮盘 → 松手吸附最近项并跳页（位移 >4px 才算拖，否则算点击）；键盘 `Tab` 进入后 `↑/↓` 在项间移动焦点（焦点落到哪项、轮盘就滑到哪项），`Enter`/点击触发跳页。
- **active 项**：当前页加粗染金，并作为弧线中心；`aria-current="page"` 标记（13 项中唯一）。
- **含封面页**：第 1 项即「封面」，跳回封面时重新激活 3D 渲染（与 §5.1.3 收束/恢复逻辑对称）。
- **内容让位**：13 项页名横铺需要右侧空间，故 deck 模式下给 `.page > .wrap` **动态**让位 `calc(22px + max(0px, var(--wheel-w) − 视口侧留白))` —— 只在 wrap 自带留白装不下时才补差，避免大屏白留一片。**这是本形态唯一会改变既有版面观感的地方。**
- **降级**：`≤760px` 退回**底部横向点阵**（复用既有 CSS；JS 清空内联样式并停 rAF）；`prefers-reduced-motion` / `?long=1` 下翻页引擎不启用，导航轮本就**不渲染**（维持现状）。
- **实现约束**：固定定位独立层，位于 `main` 之外（不受页面 `inert` 影响）；页名文案取自 §5.1.4 的 13 页清单、单一数据源；`backend/scripts/verify_landing_pages.js` 第 ⑧ 节静态钉住「移植特征 / 未引入 React / 兜底规则 / 键盘防护」共 16 条。
- **顺带修复的既有 bug**：此前焦点落在导航轮上按方向键，会**同时**移动焦点、翻页、并把焦点抢到页面标题（`pager` 的 keydown 未阻止冒泡 + `go()` 无条件聚焦标题）。现已停止冒泡，且 `go()` 在「焦点位于轮盘内」时不抢焦点。

## 6. 设计原则与约束（沿用，v2 不得破坏）

### 6.1 设计 Token（取自 `index.html :root`）
| Token | 值 | 用途 |
|---|---|---|
| `--bg` | 藏青深色系 | 全局背景 |
| `--text`/`--muted`/`--dim` | `#EDEFF7`/`#9AA3C0`/`#6F7899` | 正文/次要/极弱 |
| `--gold`/`--gold-soft` | `#D9A441`/`#E8C57A` | **强调色 = 交互色（accent）** |
| `--up`/`--down` | `#FF8F8F`（涨/红）/`#6FCF97`（跌/绿） | 遵循 A 股惯例：涨红跌绿 |
| `--gold-line` | `rgba(217,164,65,.22)` | 极淡金线 |
| `--radius`/`--maxw` | `12px`/`1080px` | 圆角/内容最大宽 |
| `--serif`/`--sans` | 宋体类/系统无衬线 | 衬线标题、无衬线正文 |
| `--ease-out`/`--ease-io` | 快出慢收/两端对称 | 入场/往复 |
| `--stagger` | `60ms` | 组内入场间隔 |

### 6.2 硬规则（v2 必须遵守）
1. **金色只给可点击元素**：新增装饰不得再开金。
2. **动效时长三档 + 翻页档**：140/240/520ms 沿用；翻页缓动新增一档并登记 `:root`，不得散落。
3. **降级不白屏**：WebGL/脚本禁用/reduced-motion 三路降级必须保留且 v2 强化（reduced-motion → 长页）。
4. **可访问性**：所有动效尊重 `prefers-reduced-motion`；导航轮键盘可达、对比 AA。
5. **性能预算**：3D 资源本地加载不联网；翻页/滚动不得引发长任务。
