# RSI 与 BIAS 深度学习笔记

> 目标：理解两个指标怎么算、描述什么、怎样使用、何时会失效。本文是指标学习资料，不构成投资建议，也不提供可直接照抄的买卖阈值。

## 1. 先建立直觉：它们看的是价格的不同侧面

- **RSI** 是 **Relative Strength Index** 的缩写，中文通常译作“相对强弱指标”。
- **BIAS** 通常称 **Bias** 或 **Deviation Rate（偏离率/乖离率）**，中文叫“乖离率”。它一般不是像 RSI 那样逐字母展开的英文缩写；不同资料可能写作 Bias、BIAS 或 Deviation Rate。

可以把一段价格走势想成一个人在走路：

- **RSI**像是在看最近一段路里，上行步伐相对下行步伐有多强。它描述一段时间内的**涨跌动能**。
- **BIAS（乖离率）**像是在看现在离这段路的平均位置有多远。它描述价格相对某条移动平均线的**偏离幅度**。

| 指标 | 主要回答的问题 | 不直接回答的问题 |
| --- | --- | --- |
| RSI | 最近涨的力量相对跌的力量强不强？动能是在增强还是减弱？ | 价格是否便宜、是否一定要反转？ |
| BIAS | 价格在某条均线之上还是之下？偏离均线多少？ | 均线是不是合理价值、偏离是否马上收敛？ |

**“相对强弱指标”里的“相对”不是和另一个基金或指数比较。** RSI 比较的是同一价格序列在观察期内的平均上涨与平均下跌。

## 2. RSI：涨跌动能的相对刻度

### 2.1 计算过程

给定连续收盘价 P₀、P₁、……，先计算每期变化：

- 变化量 Δt = Pt − Pt−1
- 上涨 Ut = max(Δt, 0)
- 下跌 Dt = max(−Δt, 0)

再对最近 N 期的上涨、下跌分别求平均：

- RS = 平均上涨幅度 ÷ 平均下跌幅度
- RSI = 100 − 100 ÷ (1 + RS)
- 等价地：RSI = 100 × 平均上涨幅度 ÷ (平均上涨幅度 + 平均下跌幅度)

RSI 的范围是 0 到 100。平均上涨与平均下跌相等时，RSI 为 50；前者更大时 RSI 高于 50，后者更大时低于 50。它不是“上涨概率”，也不是“上涨了多少百分比”。

### 2.2 Wilder 平滑与手算例子

Wilder 的经典 RSI 先用 N 个价格变化初始化平均涨跌幅；之后不是每次简单地只看最近 N 期，而是递推平滑：

- 平均上涨_t = (平均上涨_t−1 × (N−1) + 本期上涨) ÷ N
- 平均下跌_t = (平均下跌_t−1 × (N−1) + 本期下跌) ÷ N

这让较早的变化逐步淡出，同时保留一定记忆。不同软件若改用简单移动平均或其他平滑方式，数值可能不同；比较 RSI 前要确认公式、周期和数据源一致。

**小算例**：用 5 次变化作演示，价格变化依次为 +1、−1、+2、−1、+2。初始平均上涨为 (1+0+2+0+2)÷5 = 1，平均下跌为 (0+1+0+1+0)÷5 = 0.4，因此 RS=2.5，RSI≈71.4。这只说明这 5 次变化中，上涨幅度相对更强；不表示接下来必跌。

### 2.3 周期、区间与常见信号

- RSI(14) 中的 14 表示 14 个**图表周期**：日线图是 14 个交易日；周线图是 14 周。周期越短，指标通常越灵敏，也更容易受噪声影响。
- 传统用法常把 70 以上称为“超买”、30 以下称为“超卖”。它们是历史上常用的观察区，不是自动卖出/买入命令。Fidelity 的技术指标说明也提醒：强趋势中 RSI 可能长时间处于高位或低位；牛市和熊市中的 RSI 常见活动区间也可能不同。
- 50 附近可作动能强弱的参考分界，但单独穿越 50 仍可能反复，不宜把一次穿越等同于趋势确认。
- **背离**：价格创新高而 RSI 高点降低，表示上涨动能没有同步增强；价格创新低而 RSI 低点抬高，表示下跌动能没有同步增强。它提示走势可能变弱，但不确定反转何时发生，也可能持续背离。
- **失败摆动**：观察 RSI 自身的高低点是否先形成失败结构，再跌破或突破 RSI 的前一个摆动点；它是动能结构信号，不是保证获利的形态。

RSI 的边界值也要留意：若一段时间没有下跌，公式会趋近 100；若没有上涨则趋近 0；完全没有价格变化时公式出现 0/0，软件可能采用不同约定或显示空值。涉及程序回测时应明确规定并测试这些边界。

## 3. BIAS：价格离均线有多远

### 3.1 计算和读数

设当前价格为 P，N 期简单移动平均为 MA_N：

**BIAS_N = (P − MA_N) ÷ MA_N × 100%**

- BIAS 为正：价格在该均线之上。
- BIAS 为负：价格在该均线之下。
- BIAS 接近 0：价格接近该均线。
- 绝对值越大：相对这条均线偏离越远。

**小算例**：若价格为 105、20 期均线为 100，则 BIAS_20=+5%；若价格为 95，则 BIAS_20=−5%。这不是“高估/低估 5%”的基本面结论，只是价格与所选均线的数学距离。

BIAS 的 N 可以取不同长度，分别观察短、中、长期偏离。常见软件可能提供多条 BIAS 线，但参数设置并非统一标准。BIAS 阈值受标的波动、均线周期和市场状态影响，不能把某个固定正负百分比当成所有基金通用的反转线。

### 3.2 BIAS 与均线“乖离”不是所有时候都指同一个量

常见的 BIAS 是“价格相对一条均线的偏离”。另一种常被称为“双均线乖离/均线差”的量是：

**(短期均线 − 长期均线) ÷ 长期均线 × 100%**

前者看**价格相对均线**的位置，后者看**两条均线相对彼此**的位置。它们同属百分比偏离表达，但输入不同、含义不同，阅读图表或代码时应核对具体公式。东方财富和富途的 BIAS 说明均以价格与 N 期均价的偏离为核心定义。

## 4. 两个指标怎样应用，又怎样失效

### 4.1 震荡行情：观察偏离与回归

在价格围绕某个区间来回波动时，较大的负 BIAS、偏低 RSI 可以作为“价格偏弱/偏离较大”的观察线索；但更稳妥的研究问题是：随后是否出现动能改善、价格止跌等确认，而不是指标一到极值就假设反转。

### 4.2 趋势行情：避免把强势误读为见顶

在持续上行中，RSI 偏高、BIAS 为正且扩大可能反映趋势强，而不必然代表马上回落；持续下跌时 RSI 偏低、BIAS 为负也不代表马上见底。先区分趋势与震荡状态，再解释指标，通常比孤立读一个数值更合理。

### 4.3 组合使用：可能互补，也可能重复计分

RSI 主要概括近期涨跌幅的相对强弱，BIAS 直接表示价格离均线的距离。它们视角不同，但都来自价格，因此并非完全独立的信息。若策略把 RSI 和 BIAS 都计入综合分，需要验证是否真的增加了样本外解释力，而不是把同一段下跌重复惩罚、把同一段上涨重复奖励。

可以把它们设计成待验证的研究问题，例如“偏离较大后，动能转强是否比单看偏离更有用？”这是一条实验假设，不是交易建议；答案需要数据检验。

## 5. 基金数据与回测口径

### 5.1 指数行情不等于基金净值

指数常有盘中行情，开放式基金通常按基金规则计算并公布单位净值。基金申购按订单接收后适用的净值和产品规则处理，投资者下单时未必知道最终成交净值。因此，不能用“当天收盘后的基金净值指标”同时假设自己也能按这个已知净值买入，否则会引入未来信息。中国基金监管规则规定申购、赎回价格以相关日基金份额净值及费用计算，并规定管理人确认申请的时限；具体产品仍应查看基金合同及销售渠道规则。

若用指数代替基金净值做研究，应说明这只是代理序列，并检查跟踪误差、成分差异、费用和分红影响。指数的盘中 RSI/BIAS 也不能当成基金的盘中真实净值信号。

### 5.2 分红、拆分与净值序列

分红会改变单位净值，但不一定代表持有人总财富同比例减少；份额拆分会改变单位净值和份额数。计算收益和技术指标时，应明确使用原始净值还是复权/总回报序列。不同口径可能产生不同 RSI、BIAS 和回测结论。缺失净值、重复日期、异常值也应先清洗，不应默默用零或随意插值。

### 5.3 一个最低限度的回测检查表

1. **信息时点**：每个信号只使用当时已公布的数据；记录可下单日和实际可得净值。
2. **完整回报**：纳入分红再投资口径、申购赎回费、基金费用及现金闲置收益；避免只比较基金净值价格涨幅。
3. **合理基准**：策略与同类、同风险暴露且同资金投入假设的基准比较。
4. **分段检验**：保留未参与选参数的样本外区间，并做滚动/不同市场阶段检验。
5. **参数纪律**：先设定少量有理论理由的参数范围；尝试很多组合后只报告最佳结果，会夸大偶然性。
6. **报告风险**：除收益外，同时查看最大回撤、回撤持续时间、交易次数、换手、极端行情表现和信号稳定性。

回测只是对历史数据和假设的模拟，不等于真实交易结果，也不能保证未来表现。SEC 投资者教育资料建议检查回测方法、费用、分红、基准和市场环境等假设。

## 6. 快速复习

- RSI：比较一段时间内平均涨幅与平均跌幅，刻画动能；它不是胜率，也不是独立估值指标。
- BIAS：价格相对某条均线的百分比距离；它不是均线本身，也不是基本面估值。
- 极端值表示“值得观察”，不等于“马上反转”。趋势、周期和数据口径会改变解释。
- 同时使用多个价格指标前，先问它们是否提供了不同信息，再用样本外检验增量价值。
