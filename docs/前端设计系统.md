# 前端设计系统 G0 · 深藏蓝×鎏金

> 版本：随项目前端搭建落地，持续维护。
> 单一真相源：`public/style.css` 顶部 `:root`。

## 1. 设计方向
- **配色**：深藏蓝 `#0A1020` 画布 + 极光贴边（靛蓝左上 / 鎏金右上）+ 玻璃纸卡片 + 鎏金 `#D9A441` 强调。
- **字体**：标题用衬线（宋体系），正文/数字用无衬线；数字 `tabular-nums`。
- **涨跌**：A股惯例，**涨红 `#FF8F8F` / 跌绿 `#6FCF97`**。
- **动效**：状态切换 150–250ms；尊重 `prefers-reduced-motion`。（未引入数字滚动等强动效，避免与「不替用户决定」的极简基调冲突。）
- **响应式**：桌面左侧边栏 6 项；手机顶部品牌栏 + 底部 4 Tab（概览/决策/持仓/更多）。

## 4. 页面数据契约
- `STATE = /api/state`：`holdings.funds`（数组，每项含 purchases[]）/ `target` / `config` / `history` / `watchlist`。
- `LIVE = /api/refresh`：`funds`（富化数组）/ `totals` / `allocation` / `plan` / `penetration`。
- `advice = /api/advice?session=am|pm`：`l1`（组合状态）/ `l2`（信号数组）/ `l3`（月度计划）。

## 5. 用法约定
- 改配色 → 只改 `style.css` `:root`。
- 改某页 → 只改 `js/pages/xxx.js`。
- 改接口/鉴权 → 只改 `js/api.js`。
- 改本地存储 → 只改 `js/store.js`。
- 新增页面 → 新建 `js/pages/xxx.js` + `app.js` 的 `PAGES` 加一行（`index.html` 无 section，路由全靠 hash，无需改壳）。

## 6. 已知坑与处理
- **模块路径约定**：`js/` 下模块互相 `./xxx.js`；`pages/` 和 `charts/` 引用 `js/` 下模块用 `../xxx.js`；引用 `vendor/` 用 `../vendor/xxx.js`。统一只有一层 `../`，避免子目录路径坑。
- **holdings.funds 是数组**：前端用 `state.holdings.funds` 直接迭代（`.forEach`/`.map`），不要 `Object.values`。
- **echarts 懒加载**：`echarts.min.js` 1MB，由 `js/charts/trend.js` 动态 `import('../charts/trend.js')` 时按需加载，**不阻塞首屏**。概览页 KPI 同步、走势图异步。
- **玻璃性能**：`backdrop-filter: blur(14px)` 在低端 Android WebView 可能掉帧；若卡，改 `--panel` 为实色 `rgba(255,255,255,0.06)` 并去掉 `backdrop-filter`。
- **WCAG AA**：主文字 `#EDEFF7` on `#0A1020` ≈ 15:1；鎏金 `#D9A441` on `#0A1020` ≈ 8.4:1；均过 AA。
