# 策略说明与运行状态

本页说明公开代码如何区分策略和计划，核对日期为2026-10-14。返回[文档导航](README.md)。基金的实际结果还受当前配置、身份、数据与申购状态影响，不能仅凭名称或流程图确认可买。

## 先看状态，再看能否交易

“每月定投”是一项由用户手动执行的月频计划，系统不指定日期、金额或当月完成情况。“可考虑买入／可加仓”是量化市场候选，还要检查申购状态、限额和资金政策。“等待机会”表示条件未满足；数据不足时保留空判断并说明问题。

基金存在分类、身份、适用范围或数据问题时，仍留在“我的基金”，问题集中展示。选择分类只决定策略入口，不能跳过官方核验。数据恢复后可恢复信号；官方证据问题须有可靠资料才能解除。正常等待、暂停申购和用户限额不归为基金数据问题。

决策页用简明状态和原因说明现状；每日复盘展开查看详细依据。双价格通道的前端名称为“下跌后回稳”和“上涨中回调”，名称调整不改变计算条件。决策页不显示综合分，部分策略的评分接口和详细依据仍保留。

## 红利月定投

合格红利基金显示“计划：每月定投”“每月定投，手动执行”。未核验或范围不支持时给出具体问题，不误显示有效计划。

计划接口的 `marketState=monthly_dca`、`displayKind=plan`、`frequency=monthly`；买入判断和综合分为空，`executable=false` 表示系统不发出可执行申购建议。申购暂停、用户限额及其他交易限制单独提示。

实时计划不再为旧趋势条件抓取全历史。月频计划不产生每日量化战役样本。每月复盘按实际录入流水的交易日自然月、基金汇总日期、笔数和金额，区分已确认与份额待确认记录；金额不表示计划额度或完成率。

旧 `dividend-trend-v1` 记录、统计口径和必要的历史数据服务保留。[旧趋势回踩图](img/strategy-dividend-flow.svg)属于历史规则。

## 黄金月计划与政策阅读

当前启用版本为 `gold-monthly-dca-v1`，`backend/data/goldMonthlyIdentity.json` 中 `releaseEnabled=true`。旧 `gold-dual-v1` 量化门禁保持关闭，不恢复择时买点。若回滚关闭月计划开关，则返回旧路由及其原有门禁，不自动启用旧量化。

状态显示“每月定投，手动执行”，日期、金额与是否执行由用户决定。首批七份额（000216、000217、000218、000307、002610、018391、018392）分别核验国内人民币场外黄金ETF联接身份；不自动覆盖白银、原油或其他商品。身份或范围不符仍显示问题，暂停申购和用户限额独立提示；不生成可执行申购建议或每日量化样本。

每日复盘的黄金条目展开后读取近期官方政策，默认90天，可选30或180天。阅读内容优先展示机构、公布日期、简短政策解读与官方原文；详细摘录和方法来源收在依据中。解读说明可能影响黄金的机制与条件，不把政策标题直接解释成确定涨跌，也不影响月计划。

来源登记覆盖美国、中国、欧元区、日本和英国，当前适配主要集中在央行公开栏目。财政、税收、贸易、制裁、黄金直接交易规则等部分来源仅登记、访问受限或尚未适配；不代表“全部政策已收齐”。正文无法可靠核验时保留标题并说明无法解读，缺项和过期情况明确提示。完整覆盖边界见 `backend/data/macroPolicySources.json`。
