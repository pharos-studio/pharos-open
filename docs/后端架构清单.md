# 后端架构清单（按职责组织）

零外部依赖、CommonJS。正式策略和回测分离；本轮重构不改变非红利规则、申购公式或持仓数据。

## 正式决策链路

```text
server：路由、鉴权、启动
  → analysis：获取净值、估值与持仓，准备输入
  → alloc/allocation：旧接口兼容服务，读取当次配置与时钟
  → decisionPipeline：路由、调用策略、评分、交易约束、组装结果
      ├─ registry → strategies：每套策略自己的完整判断
      ├─ scoring：V / M / 综合分（沪深300不使用）
      └─ tradeConstraints：申购状态、有效期与用户限制
  → advice：复用 analysis 挂载的结果，组装卡片与独立提醒
      → 服务侧保存建议历史、采集买入时机
```

纯计算不读取配置、网络或文件；流水线接收数据、配置和时间。配置不建立全局缓存，下一次请求立即读取新设置。`services/scoreConfig` 仅归一参数，`services/yieldHistory` 承接旧历史股息率读取接口。旧调用可以通过 `decisions`、`kernel` 和 `alloc/allocation` 兼容；正式策略不导入这些兼容层。

`kernel` 是薄转发，不含策略条件、矩阵、评分或文件读取；它不是新策略的必经入口。低层信号函数由各策略持有。兼容矩阵保留原字段及默认值，不代表这些字段都是本策略触发条件。

## 策略与运行状态

| 路由 | 策略文件 | 当前行为 |
|---|---|---|
| 普通 A 股宽基 | `engines/strategies/core.js` | PE × ERP；不含沪深300专线 |
| 官方身份核验合格的国内场外沪深300普通指数/联接 | `engines/strategies/broad300.js` | 共同月度PE≤25%＋回撤修复或趋势回踩；`hs300-dual-v1` |
| 海外宽基 | `engines/strategies/broadGlobal.js` | 滚动 PE 分位或 PE 回撤；ERP 与均线按现有角色保留 |
| 主题行业 | `engines/strategies/tech.js` | 回撤止跌或均线金叉；保留现有总闸 |
| 商品对冲 | `engines/strategies/gold.js` | 净值分位、趋势与止跌；保留现有总闸 |
| 红利低波 | `engines/strategies/dividend.js` | 国内指数类趋势回踩；状态输出，股息率仅参考 |

国内红利按档案核验后使用冻结趋势回踩规则，版本为 `dividend-trend-v1`，不生成综合分。数据不足时市场判断为空、不可执行；主动及海外红利暂不支持。通用兼容接口的旧 `yield/absYield`、默认及未知模式继续不可用，不转入新规则。既有持仓和组合提醒不变。

## 职责边界与兼容约束

- 策略：指标、触发条件、策略硬限制、矩阵与理由；不读取存储或联网。
- 编排：选择正式路由，连接评分与交易约束；保留 `_dec/_composite/_marketScore` 等旧挂载字段，建议页直接复用。
- 评分：权重、缺值、归一化、舍入与原硬约束归零行为不变；硬约束归零综合分时 V/M 仍保留。
- 交易约束：申购状态 24 小时有效、未知或过期不可执行、用户限额为零拦截。沪深300与普通评分策略现有政策语义差异原样保留，不借结构重构统一。
- 服务：准备输入、读取配置、组装展示、保存历史与采集复盘。建议的异常兜底沿用现有语义，不改其他策略输出。
- 公共指标：只复用真正一致的算法；沪深300与红利各自的周筛选及数据可获知时点不合并。

## 回测与验证

研究代码、模拟收益、研究数据和报告只保留本地，不进入公开版本。正式计算在 `lib/dividendTrend` 与策略层，完整净值、分红与缓存由 `services/dividendData` 负责；长序列不进入接口响应。`lib/domesticCalendar` 是正式运行日历，已核对2025、2026年上交所休市公告；其他年份需补充核验，否则不可执行。

功能验证、审计与维护脚本保留 `backend/scripts/`；研究 npm 入口不随公开版本发布。职责回归采用重构前 `5f0ce8f` 捕获的脱敏固定输入与不可变预期，测试不会自行刷新预期文件。

离线与 UTC 回归在仅含示例数据的临时副本执行，禁止在用户数据目录运行 setup 或回测写入。`verify_backtest_boundary` 检查正式依赖不进入回测目录；新增文件同样纳入脱敏审计。

## 沪深300数据与复盘

`lib/hs300Signal` 为冻结纯计算；`services/hs300Data` 获取完整净值、增量更新、日度全量核对及复权验证；`services/hs300Pe` 独立月度TTM PE缓存与60个连续月窗口；`services/hs300Identity` 只接受服务端官方证据，名称、代理锚及业绩基准不能启用。四只已审官方记录保留转型日期；其他份额须官方关系与当前策略生效日均核验，不能仅用成立日猜测。临时失败最多缓存5分钟。

`lib/hs300Calendar` 收录2013—2026年上交所年度休市与临时修正。净值和PE保守T+2可用，受实际查看时点约束；周数据与红利分别筛选，不重启Wilder初始化。新版本不读取旧单通道配置，不以人工PE或价格分位兜底，不输出V/M或综合分。

新游标位于 `strategyFunds['hs300-dual-v1']`，首个有效未被交易拦截的结果仅建基线。战役编号含版本；无法判断及交易拦截不更新转折，中断恢复按首次重新观察日期采集、保留approx说明。旧游标、战役和买入关联不动；新买入只关联同版本启用后的战役。新复盘T+30为复权净值30个观察日、未计费用；`/api/timing` 的 `versionLedgers['hs300-dual-v1']` 单列完整统计，旧账不混入新版本样本。

## 红利数据与复盘

完整净值逐页校验后再发布缓存，小时增量、日度全量复核；同代码单飞，失败不发布部分序列。采用分红再投资复权和第三方日收益自洽校验，不宣称全部官方公告已逐条认证。净值最少260日、周数据最少16周；缺公告时刻按净值日后第二个开放日可用，最新周不得用周四冒充未公布周五。日历、净值或复权不合格不回落旧规则。

新红利复盘游标放在 `strategyFunds['dividend-trend-v1']`；首个有效结果只建基线，历史游标与样本不改。新战役编号含版本，历史购买不跨版本补附。新T+30复盘用复权序列、30个净值观察日，不含费用；旧样本仍保持原口径，分组按版本隔离。
