# Pharos

> 灯塔标示方位、提示暗礁，但它从不替你开船。

跑在自己电脑上的基金积累看板。记录投入、资产与收益，为长期积累和复利目标提供策略参考；不承诺本金或收益。金额、节奏和实际交易由你决定。

- 持仓、买入记录和配置保存在本机，使用公开接口获取行情与资料。
- 零运行时依赖，使用 Node.js 内置模块和原生前端，无需安装依赖或构建。
- 手机与电脑处于同一 WiFi 时可以访问，支持添加到主屏。
- 深藏蓝与鎏金界面，红涨绿跌。

[在线项目介绍](https://pharos-studio.github.io/pharos-open/) · [完整使用指南](docs/使用指南.md) · [文档导航](docs/README.md)

## 启动

安装 Node.js 18 或更高版本，然后运行：

```bash
git clone https://github.com/pharos-studio/pharos-open.git
cd pharos-open
npm run setup
npm start
```

打开 <http://localhost:3000>。Windows 也可以依次双击 `setup.bat` 与 `start.bat`。

`setup` 从空模板生成数据文件；已有文件会跳过。第一次启动后，到“我的基金”添加自己的基金。写操作需要设置页中的 API Key，默认模板口令为 `dev`；设置了 `FUND_API_KEY` 环境变量时填写其值。

服务默认监听所有网卡，启动窗口会显示局域网地址。手机与电脑连接同一 WiFi 后使用该地址访问；需要配置后端连接时填写电脑地址。仅在本机使用可设置 `HOST=127.0.0.1`。

| 页面 | 用途 |
| --- | --- |
| 概览 | 查看资产、投入与收益变化 |

| 决策 | 查看简明状态与独立交易限制 |
| 配置 | 查看组合占比与已披露持仓的穿透分析 |

| 设置 | 配置后端连接与访问口令 |

## 策略状态

不同基金按身份和类别进入对应策略。国内红利与已核验的国内黄金ETF联接当前显示“每月定投，手动执行”。黄金月计划已启用，每日复盘展开可看近期宏观政策解读；政策仅供参考，不自动决定是否买入。基金身份和适用范围仍逐只核验。

普通A股、海外宽基（含沪深300与纳指100专线）原策略保留，普通红利与红利低波均保留；不限固定四类，也不要求所有策略只在低位投入。其他现有商品策略不变。单一主题行业与主动权益基金可添加并记录资金，状态为“仅记账”：不生成新的买入、等待、评分或减仓信号，持仓、收益、占比、购买流水和旧历史照常保留。修改记账分类不能绕过身份限制。“仅记账”不是数据错误，也不是等待建设的算法。

有策略基金的分类、身份或数据存在问题时，记录仍保留在“我的基金”，问题集中提醒；相应策略信号等待问题解除后恢复。暂停申购和用户限额作为独立交易限制展示。低位参考不保证买在最低点；海外宽基及纳指也可能长期亏损，积累目标不代表稳定收益。

各策略的适用范围、运行状态及流程图见[策略说明与状态](docs/策略说明与状态.md)。历史流程图和设计方案均有明确标识。

## 升级与数据

已有记账数据的用户，升级前先停止服务，并在项目目录之外备份同一次完整 `data/` 与代码版本。`git pull` 后首次启动可能执行数据迁移；旧份额和历史收益可能按迁移口径重算。请先阅读[升级须知](docs/使用指南.md#升级须知)，核对券商真值与费用口径。

个人状态、缓存和运行配置由 Git 忽略，公开下载仅提供空模板。第三方接口可能变更、限流或缺数据；申购费率取决于渠道，穿透分析只覆盖已披露持仓。详细说明见[使用指南](docs/使用指南.md)。

## 项目结构

```text
backend/          本地服务、策略、数据服务与校验脚本
public/           看板前端
landing/          在线介绍页样式与脚本
data/example/     空数据模板
docs/             使用、策略、架构与历史文档
index.html        在线介绍页入口
public/index.html 看板应用入口
```

本地服务提供 `public/`；根目录的 `index.html` 用于 GitHub Pages 项目介绍。研究脚本、实验报告和真实账户数据不随公开版本分发。
